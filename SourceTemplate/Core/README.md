# Core/
Código compartido entre features:
- **DesignSystem/** → tokens (colores, tipografía, spacing) y componentes
  reutilizables. Nada de estilos hardcodeados en las vistas.
- **Networking/** → cliente HTTP async/await, endpoints, DTOs.
- **Persistence/** → modelos @Model de SwiftData y helpers de queries.
- **Extensions/** → extensiones chicas y genéricas de tipos del sistema.
